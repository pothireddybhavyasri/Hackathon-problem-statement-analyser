# Data Analytics Syllabus Mapping — Hackathon Insights

**Course Code & Title:** `CS513PE: DATA ANALYTICS (Professional Elective – I)`  
**Curriculum & Regulation:** B.Tech. III Year I Sem (R24 Regulations)  
**Primary Reference Textbooks:**
1. *Data Mining Concepts and Techniques*, Jiawei Han, Micheline Kamber, Jian Pei, 3rd Edition, Morgan Kaufmann.
2. *Student's Handbook for Associate Analytics – II, III*.
3. *Introduction to Data Mining*, Tan, Steinbach, Kumar, Addison Wesley.

This document formally verifies and maps all 5 units from the academic syllabus to the concrete implementations, source code modules, application pages, and interactive demonstrations in the **Hackathon Insights** project.
